# QuoteAgent

> **Status**: Phase 0 in progress (vertical slice). Not yet production-deployed.

Portfolio + learning project. An AI agent for a fictional Dutch freight forwarder (Linkport Forwarders BV) that reads an inbound FCL Rotterdam→New York quote email, extracts the request, looks up a rate, and drafts a reply.
